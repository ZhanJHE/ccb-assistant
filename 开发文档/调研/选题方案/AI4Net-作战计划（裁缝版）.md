## 一、总纲（裁缝版）

> **把已有的模块重新排列组合，应用到新场景，讲一个新故事。** —— 绝大多数论文的本质。
> 三条操作原则：**① 反向定位**（先定层级，再在"做的人多"处选方向）；**② 模块重排**（基准模型 + 可替换模块）；**③ 编故事**（冲突 = 已有方法在新场景表现不好）。

**与本工作区铁律的兼容**：裁缝降的是"创新度期望"，**不降**"数据真实 / 出处可溯"。所有结论仍须能回答"这条我是从哪一行看到的？"。

## 二、把裁缝思路嵌回原七阶段

| 原阶段 | 裁缝化改造 |
|---|---|
| 0 范围冻结 + 硬件清点 | 加**反向定位**：毕业要求 → 期刊层级 → 方向层级；硬件清点改为"**本机可跑性清点**"（Windows 原生优先） |
| 1 增量调研 | 在原"找空白"之外，加一条"**找材料**"：在目标方向近 2 年论文里物色**做的人多、代码完整、有预训练权重**的基准模型 |
| 2 下载 PDF + 转 MD | 不变（本质是给"缝"备料） |
| 3 精读与讲述 | 精读时**只重读 Method 部分**，产出"**可替换模块池**"（注意力/特征融合/损失/解码/数据增强…10–20 个） |
| 4 Idea 生成 | 从"空白驱动"改为"**模块重排驱动**"（复刻思想 / 堆叠思想），并**捆绑 2–3 个创新点**（科研 trick 之捆绑销售） |
| 5 选题裁决 | 判据加三条**裁缝硬指标**：① 基准代码公开可得 ② **本机可跑** ③ 数据公开可下；再看故事与撞车 |
| 6 实验 | 套**三实验模板**：① 对比(SOTA) ② 消融(基准→+A→+B→+A+B，**每步涨**) ③ 实例分析(可视化)；指标不好先调超参/换指标定义/换数据集 |
| 7 写作与投稿 | **三张图**（摘要图/方法图/总结图）+ **模仿**目标期刊 3–5 篇的结构句式 + **故事五要素**（背景→冲突→主角→情节→主题） |

## 三、"水论文"作战模板（可复用）

```
① 定层级（期刊/CCF）——暂不定也行，但先知道"投哪一档"
② 基准模型（跑通即用，不必读懂全部代码）
③ 模块池（读 3–5 篇 Method，提 10–20 个可插拔模块）
④ 缝（排列组合暴力试；80% 没用是常态；一个没用就换）
⑤ 三实验（对比 / 消融 / 实例分析）
⑥ 三张图 + 模仿写作 + 2–3 创新点捆绑 + 五要素故事
```

## 四、P4 选题裁决（本轮）

**判据（事前冻结，缺一票否决）**：
1. 基准代码**公开可得**？
2. **本机（Windows 原生）可跑**？（不碰 WSL）
3. 数据**公开可下**？
4. 是否存在清晰的"**冲突**"故事？
5. 撞车风险**可控**？

| 候选 | ①代码 | ②本机可跑 | ③数据 | ④故事 | ⑤撞车 | 裁决 |
|---|---|---|---|---|---|---|
| **I7「NIDS 多轴鲁棒性」** | ✅ AIN-18 开源 harness | ✅ 纯 Python（Windows CPU） | ✅ NetFlow v2 CSV | ✅ | 中 | **主攻** |
| I5「LLM 流量预测捷径审计」 | △ 需自建 | △（LLM 重） | ✅ | ✅ | 中 | **备用** |
| I1「学习型 CC 矛盾归因」 | ✅ | ❌（需 Linux 内核补丁/Mininet） | ✅ | ✅✅ | 中 | **暂缓**（环境不满足，待 WSL/云端） |
| I3「在网 IDS 漂移维护」 | △ | ❌（需 P4） | ✅ | ✅ | 中 | 暂缓（待基座环境） |

**结论：主攻 = I7，扩展为「NIDS 多轴鲁棒性评测与增强」**（原"第四轴"太薄 → 捆绑 3 个创新点）：
- **创新点 A**：在三轴（同分布/跨域/对抗）之外，加**第四轴：时序/概念漂移**；
- **创新点 B**：**轴间交互 + 迁移方向性 + 指标敏感性**的统一分析（回答"哪个轴会翻转排序"）；
- **创新点 C**：**轻量鲁棒增强**（时间感知重加权 / 域适应 / 特征选择），证明哪些轴可低成本改善。
- **故事**：背景（NIDS 模型同分布刷分）→ **冲突**（AIN-18 证明"单轴评测会给出错误推荐"；AIN-17 证明"架构复杂度 ≠ 质量"）→ 主角（统一多轴 harness + 增强）→ 情节（三轴×多模型×多指标）→ 主题（部署前必须"多轴体检"）。

### 可宣称 / 不可宣称（冻结）

| 可宣称 | 不可宣称 |
|---|---|
| 首个把"时序漂移"与"跨域/对抗"放进**同一 harness** 的 NIDS 多轴评测 | 不宣称提出新的 NIDS 检测算法 |
| 量化"轴间交互"与"排序反转"的具体条件 | 不宣称在真实生产网络部署验证 |
| 一个可复现的多轴评测 + 轻量增强基线 | 不宣称 SOTA（只在统一协议下对比） |
