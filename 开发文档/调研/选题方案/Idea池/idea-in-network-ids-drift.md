## 1. 一句话命题（必须可证伪）

> 如果把 iGuard/FSNIC 这类**在网/近线 IDS 的模型冻结部署**后，在**流量/协议漂移**（时间切分或协议参数演化）下评测，那么其精度退化比同类软件 IDS **更严重**（因片上状态/位宽受限，重训/更新通道缺失）；补一个"**数据面可算的轻量漂移检测 + 数据面外重训/热替换**"闭环，可把漂移后精度恢复到距部署初值 X% 以内，且维护开销（额外片内资源/控制面流量）可量化。

## 2. 命门：什么结果会杀死它

- 若测量到**数据面 IDS 在漂移下退化 < A%**（且不显著比软件 IDS 更脆，A 需开题前冻结），或**现有机制其实已能在线维护** → 本 idea 不成立。
- **一次性证伪它的最小实验**：在 bmv2 上部署 iGuard 式冻结 IF 模型，按时间切分（前 70% 训练 / 后 30% 测试）测 UNSW-NB15→CIC 或同集时间切分下的精度落差；若落差小于同条件软件 IDS，则"在网更脆"前提证伪。

## 4. 已有依据（只能引用本工作区已核实的结论）

- **空白出处**：`调研卷宗/智能网络/智能网络调研.md` §7 空白 5；索引 AIN-16/AIN-19。
- **反方证据（泼冷水）**：AIN-17——18 个检测器–数据集对**无一个能流式告警**（部署就绪性普遍缺失）；AIN-6——漂移下 ETC 显著退化（说明漂移是真实威胁）。
