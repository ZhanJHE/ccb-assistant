## 0. 元信息

- **主题**：把机器学习模型（以**推理**为主）部署进可编程数据平面（P4 交换机/Tofino、FPGA、SmartNIC/DPU），在线速（Tbps 级）、微秒级延迟下完成流量分类、入侵检测、性能预测等任务。
- **边界**：
  - **含**：模型→数据平面的映射方法（树/NN/attention）、编译与部署框架、混合部署（交换机+端站/FPGA/DPU）、在网推理的应用与评测。
  - **不含**：AI for Networking（主机/控制面 ML，归 [智能网络调研](../智能网络/智能网络调研.md) AIN 专题）；在网聚合/缓存/协调等基座能力（归 [在网计算基座调研](../在网计算基座/在网计算基座调研.md) NCB 专题与 NIAC/NPD）；在网 × LLM serving（归 [在网计算与LLM serving调研](../在网计算-LLM/在网计算与LLM%20serving调研.md)）。
- **关键词 & 同义词**：in-network machine learning = in-network inference = in-network intelligence = intelligent network data plane (INDP) = in-switch classification/inference = data plane ML；P4 / Tofino / programmable switch / SmartNIC / DPU / FPGA；decision tree / random forest / BNN / binary MLP / RNN / CNN / attention on switch。

## 1. 一句话总览

**2018–2023 是"树模型时代"**（pForest/IIsy/Mousika/Henna/Flowrest：把 DT/RF 编码进 match-action 表）；**2023–2026 进入"神经网络时代 + 系统化时代"**（N3IC→Brain-on-Switch→Quark/FENIX/Chimera 把 MLP/RNN/CNN/attention 搬进数据平面；Planter/ACORN/Neuralp4/NDIF 做自动编译与分布式部署；Synecdoche/LOBIN 开辟"离线发现-在线匹配"与混合部署新范式）。**本组 Quark（INFOCOM'25，CNN 全上数据平面）与 Monic（INFOCOM'26，Tofino 上 MoE）正处路线最前沿。**

## 2. 背景与问题定义

- **为什么需要它**：流量分析/安全检测/调度决策若送到服务器或控制面做，延迟高（ms 级）、吞吐受限、视图滞后；在"包经过的地方"直接推理可得线速 + µs 级判定 + 无需流量镜像。
- **核心矛盾**：**模型表达力 vs 数据平面硬约束**——无浮点/弱算力（需量化/二值化或查表化）、片上 SRAM 10 MB 量级、pipeline stage 预算（Tofino1 = 12 级）、寄存器每包只可读一次、无循环。所有工作本质都是在给这个矛盾找不同的折中点。
- **评价指标**：吞吐（是否线速）、判定延迟、精度相对服务器 baseline 的损失（F1）、资源占用（SRAM/TCAM/stage/LUT）、支持的特征数与并发流数、TTD（time-to-detection）、可编程性（runtime 换模型）。

## 3. 技术路线分类

### 路线 A：树模型谱系（DT/RF/SVM → match-action 表）
- **思路**：把决策树/随机森林的分支判断编码成表项匹配；特征是包级/流级统计量。
- **代表**：IIsy（SoCC'18→ToN'24，NIAC2026-6）[经典]、pForest（arXiv'19，分阶段 RF）[经典]、Mousika（INFOCOM'22，知识蒸馏教师-学生）[经典]、Henna（NativeNI@CoNEXT'22，层级分类：易分类在早阶段）[经典]、MAP4（TNSM'22 框架）[经典]、Flowrest（INFOCOM'23，实用流级 RF，OpenAlex 63 引）[经典]、**SpliDT（arXiv'25，分区树 + recirculation 复用资源，5× 更多有状态特征 vs NetBeacon/Leo）**[新]、**ACORN（arXiv'25，DT/RF/SVM + ILP 规划器分布式部署，2–4× 更多特征，承诺开源）**[新]。
- **优点/局限**：天然契合 match-action、可解释；但**精度受限于数据平面可计算的流特征**（BoS 论文的核心批评），模型静态、特征工程重。

### 路线 B：神经网络谱系（NN 算子 → 数据平面原语）
- **思路**：量化/二值化或"查表化"NN 前向传播，绕过浮点与循环限制。
- **代表**：N3IC（NSDI'22，二值 MLP 上 SmartNIC，XOR+popcnt）[经典]、**Brain-on-Switch/BoS（NSDI'24，二值化激活+全精度权重查表的 RNN，滑动窗口突破 stage 数限制，端站 transformer IMIS 兜底，F1 比 NetBeacon 高 ~19%、比 N3IC 高 ~40%，Tofino1 四任务 SRAM 18–23%）**[新·本方向里程碑]、NetNN（arXiv'24，NIDS 场景 NN 部署分解）[新]、**Quark（INFOCOM'25，CNN 全上数据平面，剪枝+量化，本组）**[新]、**Monic（INFOCOM'26，Tofino 上 MoE 协同推理，本组）**[新]、**Chimera（arXiv'26，神经符号 attention 原语 + 两级 key 选择 + 硬约束级联）**[新]、FENIX（NSDI'26，交换机做特征提取+FPGA 做 DNN，交叉 NPD-7）、分布式 BNN 资源管理（NOMS'26，题录级）。
- **优点/局限**：精度上限高、可吃原始序列（免特征工程）；但要么付出量化损失（N3IC 被 BoS 证明输给树模型），要么付出表项爆炸（BoS 查表法 N=2^输入位数），大模型只能承载局部算子（Chimera/Monic）。

### 路线 C：编译与部署框架（自动化、分布式、混合硬件）
- **代表**：Planter（arXiv'22，模型→P4 多 target，NIAC2026-7）[经典]、MAP4（TNSM'22）、**Neuralp4（NOMS'25，自动生成完整 NN 模型给 PDP）**[新]、**NDIF（Computers & Security'25，分布式在网 NN 推理框架）**[新]、P4 ML Toolbox（TNSM'24，17 引 OpenAlex）、**Spina（Computer Networks'24，ILP 最优分布学习函数，安全-by-design）**[新]、P4-FPGA-SmartNIC（arXiv'25，定点+Taylor 展开，UCSD 超算中心）。
- **优点/局限**：降低工程门槛、把"部署"本身变成优化问题；但多数框架只支持小模型，对 Tofino 之外的 target 支持参差。

### 路线 D：部署形态创新与新应用
- **代表**：Jewel（INFOCOM'24，包级+流级两级联合推理，IMDEA）[新]、**Synecdoche（arXiv'25，"离线 DL 发现 Key Segment + 在线模式匹配"——把包序列特征变成表项直接匹配，F1 比统计法 +26.4%、比在线 DL +18.3%，SRAM −79.2%，开源）**[新·范式级]、**LOBIN（arXiv'26，Zilberman 组，在网金融市场预测 + 交换机/服务器混合部署，45% 流量不离开交换机）**[新·场景扩展]、DUNE（INFOCOM-W'25，UPF 分布式推理 demo，题录级）、Spinner（NOMS'24，在网流聚类）、AR/CG 流量分类（NetSoft'25，RTP 特征+L4S）、iGuard（CoNEXT'24，交换机内 Isolation Forest，交叉 AIN-16）。
- **观察**：**"数据平面不跑完整模型，只跑模型的'判定残片'"**（Synecdoche 的 Key Segment、LOBIN 的混合卸载）是 2025–2026 最值得注意的形态转变——它绕开了路线 A/B 的表达力-资源矛盾。

### 路线 E：综述、愿景与评测
- Zheng & Zilberman（IEEE COMST'23，在网 ML 权威综述，本地 PDF）、Parizotto 等（ACM CSUR'23，45 引 OpenAlex，系统综述）、IN3（IEEE CommMag'24，框架+愿景，题录级）、Bracciale 等（NativeNI'22，多机在网 ML 立场文）。
- **评测现状**：各家用各自数据集/硬件，数字互不可比（详见 §7 空白 2）。

## 6. 应用场景分布

流量分类（绝对主流：IIsy/pForest/Flowrest/BoS/Synecdoche/AR-CG）＞ 入侵检测/DDoS（NetNN/iGuard/QCNN/NetBeacon）＞ 性能预测与 QoS（LOBIN 金融、TMLCN'24 QoS、电网 synchrophasor）＞ 聚类/异常（Spinner）＞ 模型推理本身（Quark/Monic/Chimera/FENIX：网络设备当 AI 加速器用）。

## 7. 研究空白与待解决问题

1. **在网模型的在线更新与漂移治理**：所有路线部署的都是**静态模型**；主机侧已有漂移退化证据（AIN-6，漂移下 ETC 显著退化），但**数据平面侧的模型更新机制（runtime 换权重 ≠ 在线学习）与漂移检测-重训闭环无人做**。BoS 的 runtime 表项重配只解决了"能换"，没解决"何时换、换成什么、换了不出事"。
2. **评测可比性危机**：各家自有数据集 + 自有硬件 + 自有 baseline，数字互不可比（BoS 引 NetBeacon/N3IC 的对比是在自己重实现下做的；SpliDT 又批 NetBeacon 特征数受限）。**缺一个公认的在网 ML benchmark**——呼应 AIN 专题发现的"评测可信度危机"，但在网侧连"被泼冷水"的评测都不存在。
3. **大模型/attention 的完整承载边界**：Chimera/Monic 只承载 attention 的"原语"或 MoE 的协同，Quark 做到 CNN 全量但 CNN 不是序列模型；**序列到序列的完整生成式推理在数据平面仍是 0**（物理上是否合理另说——这本身就是可写的立场/测量文）。
4. **推理→网络动作的闭环**：几乎所有工作止步于"分类/检测"，**推理结果直接驱动转发/调度/限速动作的闭环系统少**（例外：QoS-aware TMLCN'24 与 LOBIN 的交易动作）。**本组 SPRINT（INT 遥测）+ Carlo（跨平面协同）恰好是闭环的另一半——差异化切入点**。
5. **多机/分布式在网推理的一致性**：NDIF、multi-node 立场文、ACORN 分布式部署开了头，但模型分片跨设备时的一致性/聚合语义无人形式化。
6. **泼冷水证据（现有）**：谱系内互批（BoS vs N3IC/NetBeacon；SpliDT vs NetBeacon）证明"前浪精度/资源确实不行"，但**缺独立第三方对"在网 ML 整体收益"的重估**（类比基座侧 NCB-2《Revisiting INA》对聚合的重估——在网推理侧 equivalents 是空白，本身即是选题）。
