## 1. 逐条核验（含事实核查）

### 1.1 【最关键】时间戳：评审前提不成立
- **核查方式**：读 baseline `src/config.py`。
- **发现**：锁定的 schema = **43 列**（29 特征 + 3 偏置列 `L4_SRC_PORT/L4_DST_PORT/DNS_QUERY_ID` + 9 环境伪影列 + `Label` + `Attack`），**无 `FLOW_START_MILLISECONDS`/时间列**；唯一带 time 的是 `FLOW_DURATION_MILLISECONDS`（**时长**，不是时刻）。
- **结论**：评审说"UNSW pcap 有时间戳、IDS2018 按天采集"——**对原始数据成立**，但**对 NetFlow v2 派生文件不成立**。因此"按流开始时间排序做真时间切分"**在本数据上不可直接实现**。
- **后果**：要拿到真时间轴，必须**换数据源**（成本上升）：① 用原始 CSE-CIC-IDS2018（Day1–10，含 Timestamp）；② 用原始 UNSW-NB15 pcap 重抽；③ 换带时间的 `CIC-IDS2017`（CSV 含 Timestamp）。**待核实**：下载后确认 v2 文件是否真无时间列（若其实有，则成本大降）。

### 1.2 "合成漂移"批评成立
- λ 混合 = **跨域严重度轴**，**不是**时间轴。草稿把它塞进 A4 是概念的偷换 → 审稿人第一刀必砍。
- **改法**：拆成 **A4a 真实时间漂移**（需带时间的数据）+ **A4b 跨域混合严重度**（λ，现有数据即可）。

### 1.3 交互分析"摆表格"成立
- 现写法（零新算法、并排成表）在学术上确实薄。**改法**见 §3 B1。

### 1.4 H1–H3 搬运成立
- 重加权/CORAL/特征选择都老。**改法**见 §3 B2：绑"诊断→处方" + 轴感知集成。

### 1.5 外部效度 / 种子
- 成立。但**RoBERTa CPU 多 seed 不现实** → right-size（§3 C）。

### 1.6 评审可能过度的地方（我要打折的）
- **"只有 XGBoost 就 Reject"**：偏严——纯评测类论文用便宜模型多轴是合理的；但确实需要 ≥1 个第三条路线模型。
- **要求 5 数据集 × 多模型 × ANOVA**：属**博士级经验研究**，超出"硕士出论文 + CPU 环境"的成本；right-size 即可。
- **Friedman 检验**：需 ≥3 模型，评审自己也说要先加模型——一致，但先加模型再说。

## 3. 改进方案（按成本分三档）

### A 档 · 必做（低成本、直接回应硬伤，本机可完成）

**A1. 诚实重构第四轴（回应硬伤 2）**
- 定义 **A4a 时间外推**（真时间，**待数据**：若 v2 无时间 → 换 CIC-IDS2017/原始 IDS2018；若拿不到 → **明说 A4a 暂缺**）与 **A4b 跨域严重度**（λ 扫描，现有数据）。
- 加 **漂移量化**（给 A4 兜底）：用 **KL / MMD / 对抗验证**统计量证明"测试窗确实偏离训练分布"，把 λ 从"我混了流量"升级成"我按 α 量级制造了漂移"。
- **滑动窗口评估**：训练固定、测试窗前移，画**性能衰减曲线**（比单点表有力）。

**A2. 把"翻转"形式化（回应硬伤 3）**
- **Kendall τ**：两轴下模型排名的秩相关；**Rank-Reversal Rate**：模型对中翻转比例；**Axis-Agreement Matrix**：轴×轴一致性矩阵。
- **交互三分类**（可证伪）：加性（降幅≈各自之和）/ 协同（更糟）/ 拮抗（更好）。
- **核心假设**：*单轴排名不能预测多轴联合排名（存在不可约交互项）* —— 若数据支持，这是**非平凡发现**，不再是"排表"。
- **指标敏感性**：同一轴下 F1 排名 vs FPR vs bal-acc 排名是否翻转 → 把"指标选择"抬成一个隐藏轴。

**A3. "诊断→处方"（回应硬伤 4）**

| 诊断（先测） | 处方 | 预期改善轴 |
|---|---|---|
| 协变量漂移（X 变，P(Y\|X) 不变） | H1 时间重加权 / H2 对齐 | A4a/A4b |
| 概念漂移（P(Y\|X) 变） | 时间重加权 + 再训练 | A4a |
| 特征级对抗偏移 | 对抗训练 / 架构选择 | A3 |
| 跨域特征偏移 | H2 域适应 | A2 |
- 先做**漂移诊断**（MMD/KL/对抗验证区分协变量 vs 概念漂移），再选处方——比"试三个模块"高一档。
- 加**代价-收益**列：推理开销 / 训练开销 / 需多少目标域数据 / 是否需标签。

**A4. 外部效度 right-size（回应硬伤 5/6）**
- 加 **1 个低成本模型**（RandomForest，baseline 已有 `rf`）；**1 个新数据集**（优先 **CIC-IDS2017**，一举两得：带时间戳 → 顺带解决 A4a）。
- **5 个 seed 只给便宜模型**（XGB/RF）；报 均值±std + **Wilcoxon**；RoBERTa 单 seed **明确标注为局限**（有 GPU 再补）。

**A5. 写作去"缝合感"（回应"缝合感外露"）**
- 正文删除"搬/复用/堆叠"，改研究语言：复用 harness →「**统一评测协议**」；重排表格 →「**跨轴排序分析**」；通用技术 →「**轴感知增强**」。**附录"缝点总表"只留内部，不进论文。**

### B 档 · 选做（中成本，视结果决定）

**B1. 轴感知集成（一个真·新增强）**
- 训练多个 "per-axis 专家"，部署时用一个小判别器判断当前流量属于哪个轴，动态选/加权。**这是有方法贡献的增强，不是搬运**（回应硬伤 4 的"真正新增强"）。
- 成本：中（多模型 + 判别器）；可只在 XGB/RF 上做，避开 LLM。

**B2. 因子实验 + 轻量统计**
- 因子 = 轴 × 模型 × 指标；报**主效应/交互效应**。**用简易秩检验（Wilcoxon）替代 ANOVA**，避免过重。

**B3. 预注册判据 G4–G6**
- **G4**：轴间排名不一致性 ≥ 阈值（如 Kendall τ < 0.5 的轴对 ≥ 1 对）；
- **G5**：≥1 个增强在 ≥1 个轴上有**统计显著**增益；
- **G6**：时间轴与跨域轴的排名**不一致**（证明两轴不可互相替代）。
- **负结果也报**："哪些修不了"与"哪些修得了"同等价值。

### C 档 · 暂缓（高成本 / 本机不现实，须诚实声明）

- **RoBERTa 多 seed**：CPU 不现实，有 GPU 再说。
- **5 数据集大矩阵**：超期。
- **纯 PQC / 真长期时间采集**：需真实网络长期抓包。

## 4. 概念层：钩子升级（回应"给论文一个真钩子"）

| 原主题 | 升级钩子 | 可证伪性 |
|---|---|---|
| "应按多轴体检选模型" | **H1 轴间不可约性**：多轴鲁棒性不能分解为单轴之和 | 若联合排名可由单轴线性预测 → 证伪 |
| — | **H2 架构决定对抗，数据决定漂移**：对抗鲁棒→架构；漂移鲁棒→数据层 | 若某架构同时改善两者（或都不改善）→ 弱化 |
| — | **H3 评测轴本身是超参数**：换轴≈换模型选择准则 | 若换轴不改选择 → 证伪 |

> 建议主钩子取 **H1（轴间不可约性）**——它直接把"重排表格"论证成"非平凡发现"。

## 6. 结论

评审**方向正确**：要把"施工图"抬成"论文"，必须补**概念（可证伪的轴）+ 方法（形式化交互/诊断处方）+ 实验（多模型/多数据集/统计）**。
但**成本要按"硕士 + CPU + 禁 WSL"right-size**，且**评审的"真时间切分"前提要修正**（v2 无时间戳 → 需换数据）。
**最短改硬路径** = A 档全做（A1–A5）+ B2/B3；B1（轴感知集成）视 M3 结果再上；C 档诚实声明为局限。

## 8. 够 B / 够 C 判据对照表（投稿前自检）

| 维度 | 够 C 的线 | 够 B 的线 | 本项目现状（2026-10-10） |
|---|---|---|---|
| 新方法 | 可用现成技术 | ≥1 个方法/定律贡献 | ❌ 无（B1 未做） |
| 数据规模 | 2 数据集 | ≥4 数据集，含真实/时间 | ❌ 2 个同族 |
| 模型族 | 2 个 | ≥4 族 | ❌ 2 个 |
| 时间轴 | 合成可接受 | **真时间** | ❌ 合成 |
| 统计 | 单 seed 可 | 多 seed + 检验 | ❌ 单 seed（LLM） |
| 发现 | 描述性 | **非平凡/可预测** | ⬜ 待 M2/M3 |
| 复现 | 代码 | 代码 + artifact | ⬜ |

> **自检规则**：上表**"够 B 的线"缺 ≥2 项** → 老实投 CCF-C / 期刊；**只缺 1 项但发现平淡** → 也是 C；**全齐 + 有 surprise** → 才搏 B。

## 9. ⚠️ 关于"挑结果 / 藏负结果"

- **可以**：探索多个 seed / 数据集 / 配置；在**验证集**上选最优配置；报均值±std。
- **不可以**：只报有利 seed/数据集、**藏掉负结果**、把挑出来的当**代表性**结论。属**选择性报告**，可被复现打掉 + 撤稿。
- **更划算的替代**：把"b+c 只在 X 条件下有用"写成**边界条件/负结果**——同样省力，且是**加分项**（[§7-7]）。
- **硬线**：数据真实、可复现、不伪造（本项目 AGENTS §规则 8 + 工作区铁律）。
