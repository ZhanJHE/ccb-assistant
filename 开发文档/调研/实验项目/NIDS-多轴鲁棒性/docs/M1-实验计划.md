# M1 实验计划 · 复现 AIN-18 三轴 harness

> 创建 2026-10-09 ｜ 状态：🟡 **进行中**（baseline 已 clone；待装依赖 + 下数据）
> 目标：**先把 baseline 跑通**（裁缝第 ② 步"跑通即用，不必读懂全部代码"），确认 AIN-18 的关键数字在本机可复现。

## 0. 复现锚点（baseline README 精确值，作为对照）

| 条件 | XGBoost | RoBERTa-LoRA | 备注 |
|---|---|---|---|
| 同分布 UNSW | 0.9966 | 0.9938 | 打平 |
| 同分布 CIC | 0.9776 | 0.9745 | 打平 |
| 跨域 UNSW→CIC | **0.8116** | 0.6582 | XGB +15.3 pts |
| 跨域 CIC→UNSW | 0.0730 | 0.0599 | 双双崩到随机 |
| 对抗 ε=0.5 | 0.7720 | **0.9448** | RoBERTa +17.3 pts |

- 关键诊断：RoBERTa 跨域 **FPR=0.7756 / bal-acc=0.5477**（F1 掩盖了近随机）；对抗轴 FPR 稳定在 0.0081。
- RoBERTa 推理比 XGBoost 慢约 **5,800×**。
- **ε=1.0 端点被 baseline 明确排除**（攻击退化到单点，非 15,000 次独立试验）。

## 1. 目的

复现 AIN-18 的三轴结论：**同分布打平 / 跨域 XGBoost 大胜 / 对抗 RoBERTa 大胜**；只做"能复现 → 前提成立"的判定，不做新贡献。

## 2. 判据（预冻结）

- **G1**：XGBoost 的 **UNSW 同分布 F1 ≥ 0.95** 且 **跨域(UNSW→CIC) F1 掉幅 ≥ 10 点**（锚点：0.9966→0.8116，掉 18.5 点）→ 前提成立，进 M2。
- 若跨域退化**复现不出** → 转纯复现短文 / 换题（回 I5）。

## 3. 变量

| 维度 | 取值 |
|---|---|
| 数据 | NF-UNSW-NB15-v2、NF-CSE-CIC-IDS2018-v2（均衡 50k/类，锁定 29 特征） |
| 模型 | XGBoost（必做，100 树，**seed 42–45**）；RandomForest（必做，低成本第三路线，seed 42–45）；RoBERTa-LoRA（**选做**，CPU 慢，单 seed 并标注局限） |
| 轴 | 同分布（×2）、跨域（双向）必做；对抗（ε 扫描）选做 |
| 指标 | binary F1、balanced accuracy、**FPR**（AIN-18 强调 F1 会掩盖近随机分类器） |
