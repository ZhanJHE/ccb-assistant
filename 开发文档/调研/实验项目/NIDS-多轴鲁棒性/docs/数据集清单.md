## 已知数据处理要点（来自 baseline README，避免踩坑）

- 两集攻击构成**几乎不重叠** → 跨域只能用 **二分类**（benign vs attack）。
- 攻击流行率差约 3× → baseline 用**均衡采样**（每类 50,000 flows）以隔离"分布漂移"与"类别先验漂移"。
- 特征集锁定 **29 个**（分阶段消融 Set C），剔除了 TTL / 包长 / TCP 窗口等泄漏特征。
- 评估集在对抗轴下**同时含 15,000 扰动攻击流 + 15,000 未扰良性流**（FPR 才可测）。
