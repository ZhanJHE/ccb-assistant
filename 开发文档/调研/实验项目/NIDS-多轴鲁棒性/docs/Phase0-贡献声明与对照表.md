# Phase 0 · 贡献声明与对照表（冻结草案）

> 创建 2026-10-09。**承诺冻结**：改动需记日期与理由（见文末变更记录）。

## 1. 一句话贡献

**首个**把"时序/概念漂移"与"跨域、对抗"放进**同一 harness** 的 ML-based NIDS 多轴鲁棒性评测；量化**轴间交互与排序反转**的条件；给出可复现的**轻量鲁棒增强**基线。

## 2. 三个创新点（捆绑销售：≥3 才像完整论文）

| # | 创新点 | 与已有工作的关系 |
|---|---|---|
| **A** | **第四轴（可证伪）**：**A4a 真实时间外推**（滑动窗口 + 性能衰减曲线，若数据含时间戳）+ **A4b 跨域严重度**（λ 扫描），并附**分布漂移量化**（KL / MMD / 对抗验证） | AIN-18 无第四轴；本工作补轴并**量化漂移**（回应"合成漂移"批评） |
| **B** | **形式化的跨轴排序分析**：Kendall τ / 排名翻转率 / 轴-轴一致矩阵 + **交互三分类**（加性/协同/拮抗）+ **指标敏感性**；核心假设 = *轴间不可约性*（单轴排名不能预测联合排名） | AIN-18 仅报"方向性"；本工作把它形式化为可证伪命题（回应"排表格"批评） |
| **C** | **诊断→处方 的增强**：先做漂移诊断（协变量 vs 概念漂移），再选处方（H1 重加权 / H2 域适应 / H3 逐轴特征）+ 代价-收益表；**可选 B1 轴感知集成**（per-axis 专家 + 判别器，真·新模块） | AIN-18/AIN-17 只诊断不修；本工作给出**有假设、有针对性**的处方（回应"搬运"批评） |

## 3. 与最危险邻居的对照表

| 已有工作 | 年/出处 | 它占了什么 | 我们凭什么不同 |
|---|---|---|---|
| **AIN-18** LLM vs Classical ML NIDS 三轴压力测试 | 2026 arXiv:2609.13511（开源） | 三轴（同分布/跨域/对抗）+ 泄漏消融 + 方向性 | 我们加**第四轴（时序漂移）**+ **轴间交互** + **增强**；并且**复用其 harness**（裁缝式：在完整代码上叠模块） |

## 4. 可宣称 / 不可宣称（冻结）

| 可宣称 | 不可宣称 |
|---|---|
| 首个"四轴合一"的 NIDS 鲁棒性评测 | ❌ 提出新的 NIDS 检测算法 |
| 量化"轴间交互 / 排序反转"的具体条件 | ❌ 真实生产网络部署验证 |
| 一个可复现的多轴评测 + 轻量增强基线 | ❌ SOTA（只在统一协议下对比） |
| 复现并扩展 AIN-18（附其数字的可复现校验） | ❌ 声称 AIN-18 有误（除非复现出反证） |
