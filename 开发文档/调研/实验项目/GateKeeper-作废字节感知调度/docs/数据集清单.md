# 数据集清单与获取方式

> 2026-10-02 建。状态图例：✅ 本轮 curl 实测门户可达（HTTP 200）；⚠️ 门户在线但 curl 被拦（浏览器可用）；❌ 当前网络连不通（浏览器/换网再试）；❓ 存在性/开放性待核实。
> 角色图例：**主** = 论文核心数据；**辅** = 佐证/泛化验证；**自产** = 受控实验制造。

## A. WLAN / 无线负载 trace（负载背景主角）

| # | 数据集 | 内容与粒度 | 高峰覆盖 | 获取方式 | 状态 | 角色 |
|---|---|---|---|---|---|---|
| A1 | **CRAWDAD**（平台，重点 `dartmouth/campus`） | Dartmouth 校园 WiFi 多年期 syslog/SNMP/tcpdump；AP 级负载序列 | 连续多年，高峰窗口上千个 | crawdad.org 注册免费账号 → 接受使用条款 → 直接下载；站内按 WiFi/SNMP/load 可再淘其他集 | ❌ curl 000（连接失败，浏览器再试） | **主**（负载预测训练/验证） |
| A2 | **MAWI / WIDE** | 日本骨干链路包级 trace，2001 年至今每日 15 分钟采样 + 长期统计 | 每日采样含忙时；日周期形状清晰 | mawi.wide.ad.jp/mawi/ 直接 HTTP 下载，**无需注册** | ✅ | 辅（日周期形状、重尾流分布参数源） |
| A3 | **WITS（Waikato）** | 新西兰 ISP 包级 trace | 连续段含高峰 | wand.net.nz/wits/，部分公开部分申请 | ❌ curl 000 | 辅 |
| A4 | WTP-1/2/4 论文数据集 | 企业网 AP 负载（WTP-1）、真实校园网 FL（WTP-2）、100 AP×3 月（WTP-4） | 论文原生高峰数据 | **读论文时查 Data Availability / 作者 GitHub**；WTP-2 有 arXiv 仓库线索 | ❓ 待核实 | **主**（若开源则是最对口数据） |

## D. 作废场景对照数据（场景②）

- **不自建数据集**：方法复现 Sieber（WTP-37）/ Zhang（WTP-39）口径，数字直接引文献；自产测量对齐其定义。
- 可选：Kaggle / Zenodo 上搜 `WiFi traffic` / `video streaming dataset` 淘补充集（质量参差，仅作补充，发现后登记 `文献索引.md`）。

## E. 自产 / 合成（论文数据主体）

| # | 名称 | 怎么来 | 角色 |
|---|---|---|---|
| E1 | **作废场景数据**（场景①②③） | 受控实验自产：netem 注入中断 / UI 自动化刷视频 / 按 trace 形状 tc 整形造高峰。**单场景数小时，无挂机需求** | **主** |
| E2 | **剧本化合成家庭 trace** | 设备 + 脚本按家庭作息驱动（白天心跳、晚间集中视频/下载/同步） | **主** |
| E3 | **参数化合成负载序列** | 用 A1/A2 拟合参数（峰谷比、高峰时长、流大小重尾、ON/OFF），生成任意长/任意峰强序列压测 | 辅（压力扫描） |

## 使用纪律

1. 下载前读各站 Acceptable Use Policy；CAIDA/CRAWDAD 要求署名与引用格式，写论文时照抄其 citation 段；
2. 数据集到位一个就在本表登记实际路径（`results/datasets/<名>/`）与元信息；大数据不入 git；
3. 论文数据可用性声明：E1/E2/E3 全部开源 + A/B/C 给公开链接。
